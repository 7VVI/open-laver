# 会议纪要提炼技能

## 目标
把原始的会议记录提炼为清晰的纪要，并抽取可执行的行动项。

## 步骤
1. 获取原始素材：用户粘贴的文本，或用 read_file 读取笔记/转写文件。
2. 提炼为以下结构：

```
# 会议纪要

- 主题：
- 时间：
- 参会人：

## 讨论要点
1. ...

## 决议事项
- ...

## 行动项 (Action Items)
| 事项 | 负责人 | 截止时间 |
| --- | --- | --- |
| ... | ... | ... |
```

3. 用 write_file 保存为 `会议纪要_YYYY-MM-DD.md`。
4. 若存在明确带时间的跟进事项，可主动建议用 cron_schedule 设置提醒，或用 task_create 建立跟进任务。

## 注意
- 行动项必须可执行、有负责人；信息缺失时向用户确认，不要臆测负责人。
- 区分「决议」（已定）与「讨论要点」（未定），不要混淆。
