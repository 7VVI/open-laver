# 周报生成技能

## 目标
把零散的工作内容整理成条理清晰、可直接提交的周报。

## 步骤
1. 收集素材：询问或读取本周的工作项。可用来源：
   - 用户直接口述的内容
   - 工作目录下的笔记文件 (用 glob 找 `*.md`、`*.txt`)
   - 若在 git 仓库，可用 shell 执行 `git log --since="7 days ago" --oneline` 获取提交记录
2. 归类：将工作项按「主要成果 / 进行中 / 下周计划 / 风险与问题」四类归纳。
3. 生成周报，使用以下模板：

```
# 工作周报 (YYYY-MM-DD ~ YYYY-MM-DD)

## 一、本周主要成果
- ...

## 二、进行中的工作
- ...

## 三、下周计划
- ...

## 四、风险与需要协调的问题
- ...
```

4. 用 write_file 将周报保存为 `周报_YYYY-MM-DD.md`（放在工作目录），并把内容摘要回复给用户。

## 注意
- 措辞客观、量化成果（数字、完成度）。
- 不要编造未提供的工作内容；素材不足时先向用户追问。
